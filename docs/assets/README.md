# Public demo assets

This directory is reserved for reviewed, redacted screenshots, GIFs, and small text evidence.

No generated UI or synthetic terminal screenshot is checked in. Jetson captures are pending. Before adding an asset, verify that it contains no model bytes, private manuals, host paths, usernames, IP addresses other than loopback, device serial numbers, tokens, or unbounded logs. Record the producing commit and exact command in `docs/demo.md` or beside the asset.
