# M10.2 受限工具、Agent 与有界 Session 原型

状态：`IN_PROGRESS`。本阶段不修改 RAG 排序、M9.1B holdout 或 M10.1 KV 实现。

## 最小范围

- `search_manuals`：只读搜索 `knowledge/manuals/*.md`；
- `read_manual`：只读读取手册，禁止绝对路径、`..`、URL 和目录越界；
- `lookup_fault_code`：只读查询冻结的本地故障码 manifest；
- Agent 计划固定为最多 3 步，工具名白名单，不允许模型自行执行命令或循环；
- SessionStore 仅保存进程内最近有限轮对话，支持容量上限和 reset；它不是持久化 KV，也不代表底层多 session KV。

每次工具调用记录工具名、参数、状态、耗时和错误。无 RAG 证据时 Agent 不调用生成模型；生成回答只能携带检索返回的 citations。

## M12 General Explanation

JSONL 新操作为 `{"request_id":"unique-id","op":"explain","session_id":"session-a","query":"什么是液压系统中的空化？"}`。
`answer` 是默认的 `manual-grounded` 模式：只依据当前 RAG 检索结果，有证据才调用模型，且必须返回有效 `[S1]` 等引用；无证据返回 `NO_EVIDENCE`。`general-explanation` 必须由调用方显式选择，仅用于非设备特定的一般知识说明，返回 `mode="general-explanation"`、空 `citations` 和免责声明，不属于设备诊断、维修授权或安全操作建议，也不得伪造手册结论。两种模式只向同模式的最近 session 历史提供上下文，turn 中记录 `mode`。

涉及维修/安装/调试/排故/保养步骤、带压操作、旁路或复位安全联锁、绕过保护、危险化学品处置及人体安全关键操作的问题，`explain` 返回 `GENERAL_EXPLANATION_REJECTED` 且不调用模型。提示要求中文回答、不假设型号或现场参数、不输出 citation 标记，并在设备特定或危险问题上建议查阅受控资料并由合格人员确认。

## 明确不做

Shell 执行、网络访问、写文件工具、任意 Python 执行、无限 Agent、自动工具发现、LRU/TTL 持久化、多进程 session、VLM 图片 session 和生产鉴权。

## 当前实现

代码位于 `scripts/agent_m10_2.py`，live CLI 位于同一脚本，契约测试位于 `tests/test_agent_m10_2.py`。在已有 M9.2 RuntimeService 和索引启动后可运行：

```bash
python3 scripts/agent_m10_2.py \
  --session-id agent-demo-001 \
  --query "BX-9 的 E42 故障是什么意思？"
```

该原型尚未接入 RuntimeService 的独立 `/v1/agent` 路由，也未宣称多用户生产能力；当前 session store 只在单个 Python 进程内有效。它不代表生产鉴权、授权边界或安全认证。
