## Paired results

Percentage is `(Q8 / Q4 - 1) * 100`. A negative latency percentage favors Q8; a positive resource percentage means Q8 used more.

| Metric | Q4 median | Q8 median | Q8 versus Q4 |
| --- | ---: | ---: | ---: |
| Model ready, one initialization | 4,808 ms | 6,894 ms | +43.39% |
| TTFT | 112 ms | 100 ms | -10.71% |
| Decode throughput | 15.101 token/s | 15.227 token/s | +0.83% |
| Runtime total | 8,491 ms | 8,422 ms | -0.81% |
| Client total | 8,558.282 ms | 8,490.516 ms | -0.79% |
| Jetson unified RAM | 12,458 MB | 13,928 MB | +1,470 MB / +11.80% |
| CUDA model buffer | 1,834.83 MiB | 3,127.61 MiB | +1,292.78 MiB / +70.46% |
| GPU temperature | 57.281 C | 57.250 C | -0.031 C |
| VDD_GPU_SOC board rail | 9,556 mW | 10,698 mW | +1,142 mW / +11.95% |

Q4 and Q8 each produced one deterministic output within their own 15-sample run, but the output text differed across quantizations. This benchmark does not score answer quality, so the text difference cannot be interpreted as a Q8 quality improvement.

Under this specific short text workload, steady-state decode throughput and total latency are effectively close: Q8 measured only 0.83% higher median decode throughput while using substantially more model memory and taking longer to initialize. This evidence supports Q4_K_M as the deployment-first candidate for the current 32 GB AGX Orin target based on resource efficiency, not on a claim that Q4 is faster.

## Claim boundary

This comparison covers one fixed, short, serial text workload. It does not establish statistical equivalence, production tail latency, long-run thermal behavior, wall power, VLM image performance, RAG quality, or general model quality. Image and longer-context trade-offs require separate measurements.
