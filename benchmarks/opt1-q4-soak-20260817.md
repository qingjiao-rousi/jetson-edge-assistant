# OPT-1 Q4 Prefix Reuse soak

Status: **REVIEWED 30-MINUTE STABILITY RESULT**

This is a paired formal soak audit for the real Qwen2.5-VL `MtmdBackend`
single-hot, text-only experiment. It validates one Q4, serial Runtime
configuration on a Jetson AGX Orin. KV memory and low-level APIs remain from
`llama.cpp-omni`; EdgeOmni owns the Runtime lifecycle and validation policy.

| disabled | 1801.610 s | 647 | 0 (0.00%) | one hash | 0 for all requests |
| single-hot | 1800.218 s | 1803 | 0 (0.00%) | same one hash | 1803/1803 positive hits |

Both modes produced the same unique output SHA-256:
`7716b89dfcc0f97facbf3ead58c08202332636c24d53c9937ab604858570a191`.
The paired audit also found equal Runtime prompt/output/finish shapes.

The two serial soaks were not collected in one time window: disabled ran on
2026-08-14 and single-hot ran on 2026-08-18. Therefore 647 versus 1803
requests is not a strict paired throughput comparison and must not be used to
claim a throughput multiplier. Prefix Reuse latency gains remain supported by
the same-commit, same-protocol Runtime-length matrix.

## Boundaries

This does not validate a multi-user cache, RAG/Agent session integration,
image KV reuse, Q8, concurrency, production caching, a production SLA, or a
KV leak conclusion. A 120-minute soak, fault injection, real RAG LCP
distribution, and any Agent/RAG session mapping remain future work.
